ParkVision

Find free parking spaces from a single camera image. A small CNN classifies every space as empty or occupied, running entirely in your browser. It was trained on one parking lot (UFPR) and scores 94.1% on a lot it never saw (PUCPR). Code and write-up on GitHub →
